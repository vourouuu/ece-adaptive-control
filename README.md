# ECE - Adaptive Control
This course, taught by Associate Professor Charalampos Bechlioulis, is part of the 8th semester curriculum at the Department of Electrical and Computer Engineering, University of Patras.
Throughout the semester, we were assigned four practical exercises, which I have included in this Git repository.

---

## books
This folder contains two books and Control Map file.

## homeworks
This folder contains the four homework assignments of the course.

## lab
This folder contains MATALB code, siulation diagrams (figures) and report.

## lectures
This folder contains material from the nine lectures of the course, including slides and code.

## project
This folder contains JavaScript code, siulation diagrams (figures), videos of simulation (simulations), report and presentation of the [Rocket Landing](https://janismac.github.io/ControlChallenges/) project.
